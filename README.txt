Anusha Anumula - portfolio

What's in this folder
  index.html                 the whole site (styles and scripts are inside it)
  Anusha_Anumula_Resume.pdf  the resume the site links to

Keep both files together in the same folder.

Easiest ways to put it online (all free):
  Netlify Drop:  go to app.netlify.com/drop and drag this folder onto the page.
  GitHub Pages:  create a repo, upload both files, then Settings > Pages >
                 deploy from the main branch. The site appears at
                 <username>.github.io/<repo>.
  Vercel:        import the folder or repo as a static site.

To preview locally, just double-click index.html.

Notes
  - "Ask about my work" uses the instant answers built into the page, so it works anywhere.
  - Fonts load from Google Fonts; everything else is in index.html.
  - To change text, open index.html in any editor and search for the words.
